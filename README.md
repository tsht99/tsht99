# tsht99

Webエンジニア

大学では情報系分野を学び、卒業研究では機械学習を用いた時系列データの異常検知に取り組みました。  
業務では TypeScript を中心に、Web アプリケーションや生成AIを組み込んだサービスの設計・実装・テストに携わってきました。  
特に、業務ルールを実装上の制約として明確にすること、変更しやすい設計、自動テストや開発ルールによる品質維持を重視しています。

## 技術スタック

### 業務経験

- **言語:** TypeScript
- **フロントエンド:** Vue.js, Element Plus
- **バックエンド:** NestJS, TypeORM
- **データベース:** PostgreSQL, MongoDB

## 主な成果物

### [TimeCard](https://github.com/tsht99/time-card-portfolio)

小規模店舗向けの勤怠管理 Web アプリケーションです。  
勤怠・給与計算の業務ルール、権限制御、同時更新時の整合性、自動テストまで含めて設計・開発しています。  
詳細は公開用リポジトリの README にまとめています。

## 開発で大切にしていること

機能を実装して終わりではなく、設計・実装・テスト・デプロイ・運用まで含めて、  
「なぜこの設計にしたのか」を説明できるソフトウェア開発を大切にしています。
